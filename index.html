AI · NLP

Sulat at Marka: Bilingual Automated Essay Scoring

An AI system that scores essays written in English, Tagalog, or Taglish using XLM-RoBERTa. It places each essay in a performance level (Below Average, Average, or Above Average) against a rubric and shows the result in a simple web interface with a gauge and explanation.

  • XLM-RoBERTa
  • NLP
  • Python

GIS · Spatial Analysis

Fire Hazard Mapping System of Mandaluyong City

A GIS web application for local emergency response. It maps fire risk across Mandaluyong, tracks incident reporting in real-time, and uses time-series forecasting to highlight vulnerable areas for fire safety planning.

  • GIS
  • React
  • Node.js
  • PostgreSQL

Automation · Workflow

BFP Inspection Order Management System

A workflow automation built for the Bureau of Fire Protection Mandaluyong. It syncs inspection orders between Google Apps Script, Microsoft Graph API, and OneDrive Excel, automatically generating PDF inspection documents to cut manual paperwork.

  • Google Apps Script
  • MS Graph API
  • Automation

A 2D platformer game developed in Godot Engine. Features custom player physics, water-shooting mechanics, multiple level designs, and boss encounters themed around firefighting in Mandaluyong City.
